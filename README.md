# 🎼 Pentagrama Interactivo - Solfeo Completo

## Descripción
Una herramienta educativa e interactiva diseñada para la enseñanza y práctica del solfeo. Este proyecto permite a los usuarios interactuar con un pentagrama digital, colocar figuras musicales, silencios y signos de expresión, con la capacidad de reproducir la melodía generada mediante síntesis de audio en tiempo real.

Como estudiante de **Relaciones Públicas (UNLaM)** y apasionado por la producción musical, desarrollé esta interfaz para cerrar la brecha entre la teoría musical y la interactividad digital.

https://mi-pentagrama-musical-390ldnxio.vercel.app/


## 🚀 Funcionalidades Clave
- **Edición en tiempo real:** Colocación dinámica de notas (desde Do4 hasta Do6) sobre un Canvas de HTML5.
- **Motor de Audio:** Uso de `Web Audio API` para generar frecuencias sinusoidales precisas según la nota y duración seleccionada.
- **Selector de Compás dinámico:** Soporte para múltiples métricas (4/4, 3/4, 2/4, 6/8, 9/8, 12/8, 2/2, 3/8, 5/4, 7/4).
- **Paleta de Símbolos Completa:** - Figuras: Redonda, blanca, negra, corchea, semicorchea, fusa.
  - Silencios correspondientes.
  - Alteraciones (Sostenido, Bemol, Becuadro).
  - Signos de expresión (Piano, Forte, Staccato, Acento).
- **Metrónomo Integrado:** Herramienta de sincronización a 120 BPM.

## 🛠️ Tecnologías Utilizadas
- **HTML5 Canvas:** Para el renderizado gráfico del pentagrama y la simbología musical.
- **CSS3 (Custom Properties & Flexbox/Grid):** Interfaz moderna con estética "Dark Mode" y diseño responsivo.
- **Vanilla JavaScript:** Lógica de manipulación de arrays para gestionar los elementos musicales y sus posiciones en el eje Y.
- **Web Audio API:** Síntesis de sonido sin dependencias externas.

## 🎹 Cómo usarlo
1. Selecciona el **Compás** deseado.
2. Elige una **Figura o Silencio** de la paleta.
3. Haz clic sobre el pentagrama para posicionar el elemento.
4. Presiona **"Reproducir melodía"** para escuchar tu creación.
